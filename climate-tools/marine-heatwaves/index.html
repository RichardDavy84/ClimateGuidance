Data, probabilities and location selection

The map shows the highest threshold category reached by any of the 51 ensemble members in the selected month, using the source duration rule. The probability table shows the percentage of members meeting each category’s threshold rule. Missing samples break a run. The ensemble plot uses degrees Celsius and retains the five supplied category thresholds.

Production-zone values are equal-weight averages of the intersecting forecast grid cells. A map-point selection uses its nearest forecast cell. The browser version corrects the original array indexing so a zone average includes only its selected coordinate pairs. The background plot bands retain the original 18°C and 20°C thresholds. Categories are exceedances, not mutually exclusive outcomes.
