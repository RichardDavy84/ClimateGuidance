About the data

Forecasts are based on the ECMWF seasonal prediction system (51-member ensemble) available from the Copernicus Climate Data Store (CDS). Ensemble percentiles are computed for each month and statistically downscaled to ~1 km resolution using the KrigR package with customized high-resolution topography covariates. Forecasts are bias-corrected using historical conditions from the ERA5-Land reanalysis.

The map displays the median at the original app’s coarsened map resolution. Point values retain the native grid and bilinear interpolation.

What do the lines mean?

The solid blue line is p50 (the ensemble median). Dashed blue lines show p25 and p75; dotted grey lines show p05 and p95. These describe the supplied ensemble’s spread, not guaranteed bounds. Missing values remain missing. The map colour scale is capped at 100 cm; point plots retain values above 100 cm.
